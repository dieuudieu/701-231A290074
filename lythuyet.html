Câu 1. position: absolute và relative

position: relative dịch chuyển phần tử so với vị trí ban đầu và vẫn giữ chỗ trong bố cục. position: absolute đưa phần tử ra khỏi luồng bố cục và định vị theo khối chứa được xác định bởi tổ tiên có position khác static (nếu có). 

.product { position: relative; }
.badge { position: absolute; top: 8px; right: 8px; }

Ví dụ: thẻ sản phẩm dùng relative, nhãn giảm giá dùng absolute nằm ở góc trên. Để responsive, kết hợp max-width, Grid/Flexbox và media queries; tránh tọa độ cố định làm chồng chéo trên màn hình nhỏ. Hai thuộc tính không ảnh hưởng trực tiếp đến deploy hosting nhưng ảnh hưởng giao diện trên các thiết bị.

Câu 2. Domain, hosting và DNS

Quy trình: (1) mua hoặc đăng ký tên miền; (2) chọn hosting; (3) upload file HTML/CSS/JS hoặc kết nối Git; (4) cấu hình DNS theo hướng dẫn của nhà cung cấp; (5) bật HTTPS và kiểm tra trên trình duyệt.

DNS phân giải tên miền đến đích thích hợp: bản ghi A trỏ tới IPv4, CNAME trỏ tên miền sang một tên miền khác. GitHub Pages và Netlify hỗ trợ deploy website tĩnh mà không phải tự vận hành server.

Rủi ro: không bật HTTPS, để lộ API key trong JavaScript, cấu hình DNS sai, phụ thuộc thư viện lỗi thời hoặc cấu hình domain trỏ đến dịch vụ không còn kiểm soát. Cần quản lý tài khoản bằng xác thực mạnh, bật HTTPS và không đưa bí mật vào mã frontend.

Câu 3. let, const và var

var có function scope, được hoisting và khởi tạo undefined; có thể khai báo lại và gán lại. let và const có block scope, được hoisting nhưng không thể truy cập trước khai báo vì Temporal Dead Zone. let cho phép gán lại, const không cho gán lại biến (nhưng nội dung object vẫn có thể thay đổi). 

console.log(a); // undefined
var a = 10;
console.log(b); // ReferenceError
let b = 20;

Để debug, mở Chrome DevTools bằng F12, xem lỗi tại Console, chọn file trong Sources, đặt breakpoint và quan sát biến ở Scope. Ưu tiên const, dùng let khi cần gán lại và hạn chế var.

Câu 4. Event Delegation

Event Delegation là kỹ thuật đặt một event listener trên phần tử cha và dùng cơ chế bubbling để xử lý sự kiện phát sinh từ các phần tử con, kể cả phần tử được thêm sau. 

const list = document.querySelector('#list');
list.addEventListener('click', function(e) {
  if (e.target.matches('li')) e.target.remove();
});

Ví dụ danh sách công việc động: chỉ cần một listener trên ul để xóa li được nhấp. Kỹ thuật này giảm số lượng listener, tiết kiệm bộ nhớ, dễ bảo trì; kết hợp HTML tạo cấu trúc danh sách và CSS dùng :hover để thể hiện trạng thái tương tác.
